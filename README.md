# ملعب المخ — Brain Arena

لعبة ذكاء للموبايل والكمبيوتر، ملف واحد `index.html` (HTML + CSS + JavaScript، من غير مكتبات).

- تشغيل: افتح `index.html` في أي متصفح، أو من اللينك المنشور.
- الاختبارات: `npm i playwright` ثم `node tests/test.js` (بيشغّل Chromium ويلعب الألعاب الثلاثة بمقاسات شاشات مختلفة).
- النسخ الاحتياطية: `backups/` + تاريخ git (كل نسخة مستقرة ليها tag زي `v1-stable`).
- التغييرات: `CHANGELOG.md`.
