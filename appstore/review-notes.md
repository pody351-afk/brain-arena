# إجابات النماذج في App Store Connect

## ملاحظات لفريق المراجعة (App Review Information → Notes)
No login is required. Everything works as soon as the app opens.
Online features are optional:
1) "العب مع صاحبك" (Play with a friend): create a room, a second device enters the 4-character code.
2) "الأصحاب والترتيب" (Friends & Leaderboards): tap "انضم" (Join) with any name. No email/phone.
User-generated content is limited to the display name. Names are filtered for offensive words; any player can be reported/blocked with the ⚑ button; accounts can be deleted in-app (Friends & Leaderboards → Friends → "امسح حسابي…").
The online server runs on a free hosting plan and may need up to ~1 minute to wake up on first connection.
(لازم تضيف هنا رقم تليفونك وإيميلك في خانات Contact Information، Apple بتطلبهم.)

## التصنيف العمري (Age Rating)
كل الأسئلة عن العنف والجنس والمقامرة والرعب والكحول والمخدرات: **None**.
Unrestricted Web Access: **No**. Gambling/Contests: **No**.
سؤال المحتوى اللي بيعمله المستخدمين: اللعبة فيها أسماء لاعبين بس (من غير شات ولا صور)، مع فلتر وبلاغ وحظر. جاوب بالصدق حسب الأسئلة، والنتيجة المتوقعة 4+ أو قريب منها، وApple هي اللي بتحدد.

## خصوصية التطبيق (App Privacy)
Data Not Used to Track You. الإعلانات: مفيش.
الأنواع اللي بتتجمع (وكلها للوظيفة الأساسية App Functionality، ومربوطة بالهوية Linked to You، ومش للتتبع):
- Contact Info ← Name (الاسم اللي المستخدم بيكتبه، لو انضم للترتيب)
- Identifiers ← User ID (الرمز العشوائي للجهاز)
- User Content ← Gameplay Content (أحسن النتايج)
مش بنجمع: Location, Contacts, Photos, Diagnostics, Purchases, Email, Phone.
ملاحظة: الخطوط بتتحمّل من Google Fonts (الـIP بيوصل لجوجل وقت التحميل). دي مذكورة في سياسة الخصوصية.

## التشفير (Export Compliance)
متظبط في التطبيق (ITSAppUsesNonExemptEncryption = false): بنستخدم HTTPS/WSS العادي بس.
